# 数据源读取、选图与追溯

## 来源识别

先给每个实际使用的来源分配稳定编号（如S01），记录标题、作者、年份、版本、DOI/URL或本地文件路径，以及来源角色。来源角色包括核心论文、支撑论文、补充材料、用户笔记、用户实验数据和外部背景。

| 来源 | 读取方式与边界 |
|---|---|
| PDF | 先读文本、章节、图注和表格位置，再渲染拟使用图所在页；仅在文本不可用时使用OCR |
| URL / DOI | 解析正式发表信息，获取可访问正文与补充材料；保留实际使用版本，不把摘要当全文 |
| 本地文件夹 | 先清点相关文件，识别主文/补充/重复版本；只读取该任务指定范围 |
| Zotero | 用可用连接及相应技能读取选定条目、附件和笔记；连接或全文不可用时报告具体缺口，不改库 |
| 笔记 / 文档 | 作为用户问题、背景与线索，科学结论回查其引用原文；标记用户分析 |
| 数据表 | 读取表头、单位、数据范围与说明，区分原论文摘录和用户实验；保留变换或汇总方法 |

来源无法访问时，优先查找作者、出版方或可信学术存储中的公开版本。付费、登录或访问限制不能绕过；关键内容仍不可得时，向用户说明缺口并请求可访问资料。可以继续整理已知部分，但不能伪造全文阅读、实验或完整产物。

## 联网补充

指定数据源是主体，联网用于补齐正文、补充材料、清晰图及必要背景。优先原始论文、作者代码库、正式机构和项目页面。不擅自把任务扩展为与目标无关的大规模检索。

来源清单区分用户输入与联网补充。正式版和预印本有冲突时，优先任务指定版本；没有指定时以适合所讲结果的正式版本为主，说明差异。补充图号与主文图号分别记录。

## 图文匹配

选择每张图前，先写清它支持的页面结论，再读取完整图注和相关方法/结果段落。弄清分组、坐标、尺度、颜色、统计标记与限制后再写中文解释。

有网络架构的核心方法必须列入网络结构图的检索、提取与页面计划；优先论文主文，其次补充材料及作者官方资料。图文计划同时覆盖背景、方法与创新证据，不能只收集视觉效果图。自绘网络结构仅在来源足以确认时使用，并注明整理依据。

- 架构图解释输入、核心交互与输出；实验图解释条件和结果；背景图片说明应用价值。
- 多面板图可以分开展示，但必须保留必要面板标记、图例、比例尺和坐标。不能通过选择性裁切掩盖反例或改变比较。
- 不默认提取整篇论文的全部图片。优先提取将用于叙事的图，并保留需要的上下文。
- 原图分辨率不足时，优先从PDF矢量内容、高清原页或作者公开原图重新提取。避免将页面截图反复放大。
- 作者演示视频的静态帧可以用于说明实际画面，记录来源和大致时间；不得改变科学图内容。
- 自绘解释图应明确标为“示意”或“整理自”，与原始实验图分开。不以生成图片冒充实验、真实部署或测量数据。

## 表格与数据图

原文有明确数值或用户提供数据表时，建立可核对的数据摘录，制作原生可编辑表格或数据图。记录表号、行列筛选、单位与计算。必要重绘保留原图以便复核。

如果只有曲线图片、没有明确数值，默认使用原图。不凭视觉估读生成看似精确的结果。用户明确要求近似数字化时，说明近似方法和误差，不能将近似值称为作者原始数据。

文字、原生表格、图表与公式尽量可编辑；原始科研图以图片引用不代表整套PPT不可编辑。对无法忠实重建的复杂图，保留原图及说明，不能为了可编辑而牺牲含义。

## 来源记录的最小信息

来源清单以人能核对为准，无需设计庞大数据库。为使用的内容记录：

- 来源编号、论文/资料名称、年份、版本及入口。
- 原文位置：PDF阅读器页码、图号、面板或表格行列。区分阅读器页码和印刷页码。
- 图像文件名、对应PPT页和用途。
- 是否裁切、节选、改绘、计算或由外部背景补充。
- 关键缺失、冲突或适用条件。

如更换用户单位，额外记录官方Logo/校徽、校名或公司名和官方标准色的来源，或明确采用后备蓝色。品牌检索结果属于模板资料，不作为论文科学结论的证据。

每页在图下注明简短来源，备注保留详细定位和链接；外部背景资料不能归到核心论文的实验来源下。来源记录要随页面重排同步更新。
