# 使用示例

这些是调用方式，不是预置研究结论或现成PPT。实际模板、论文和数据由使用者提供。

## 单篇算法论文精读

```text
使用 $paper-ppt-cn。
按附带模板制作这篇论文的精读汇报，15分钟正文，问答另计。
数据源是论文PDF、补充材料和作者项目链接。
重点讲研究背景、输入输出、网络结构、关键方法、创新及实验。
默认交付四件套。
```

核心方法有网络架构时应引用原始结构图或按可靠依据整理，不能只列模块名称。

## 多篇论文专题综述

```text
使用 $paper-ppt-cn。
模板和资料文件夹已提供。围绕其中的研究主题做25分钟综述。
请筛选主线论文，其余作为支撑，并说明没有展开哪些资料。
比较问题、设计取舍和证据，不按摘要顺序罗列。
```

## 替换学校或公司品牌

```text
使用 $paper-ppt-cn。
我提供的PPT是布局模板，单位改为：填写完整单位名称。
检索对应官网的标准Logo、正式名称和主题色，替换模板各处品牌。
保留目录、分节和结束页的功能；目录条目随新内容更新。
```

只替换模板品牌，不把论文作者单位或来源署名改成使用者的单位。查不到可靠标识时说明缺口，不能制作仿造Logo。

## 实验与机制研究

```text
使用 $paper-ppt-cn。
按模板讲解附带实验论文，面向跨方向研究生。
重点解释问题、实验设计、对照、关键图和结论边界。
页数请按内容估算并说明假设，不套用算法论文的网络架构章节。
```

## 只写逐页口语稿

```text
使用 $paper-ppt-cn，为我明确指定的这份PPT写逐页口语稿。
保留文件的实际页数和顺序，按20分钟安排。
公式讲含义，图表挑关键数字，加必要转场和指图提示。
不修改PPT本身。
```

## 定向修改

```text
使用 $paper-ppt-cn，只调整附带PPT的第5至8页。
放大方法图，精简文字，保持总页数、科学内容和其他页面。
若影响已有讲稿或来源映射，同步更新受影响部分。
```
